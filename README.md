
# 🌿 GreenEarth – Forest Conservation

## About the Project
GreenEarth is a static website designed to promote forest conservation, wildlife protection, prevention of deforestation, and environmental sustainability.

The website spreads awareness about the importance of forests and encourages people to take small steps toward protecting our planet.

## Objectives
- Promote the importance of saving forests.
- Encourage wildlife and biodiversity protection.
- Spread awareness about the harmful effects of deforestation.
- Encourage tree planting and sustainable living.
- Inspire people to participate in environmental conservation.

## Technologies Used
- **HTML5** – Creates the structure of the website.
- **CSS3** – Designs the layout, colors, and responsive interface.
- **JavaScript** – Adds interactive features and functionality.

## Features
- Nature-inspired design and forest background images.
- Responsive navigation menu.
- Information about the importance of forests.
- Wildlife conservation awareness section.
- Deforestation prevention tips.
- Interactive environmental action checklist.
- Green pledge button.
- Automatic copyright year.

## How to Run the Project

1. Download or clone the project to your computer.
2. Open the project folder in Visual Studio Code.
3. Make sure all four files are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in VS Code.

## Environmental Message

Forests are essential for life on Earth. They absorb carbon dioxide, support biodiversity, protect soil, and help maintain the water cycle.

By reducing paper waste, planting native trees, protecting wildlife, and preventing unnecessary tree cutting, we can contribute to a healthier and greener planet.

**Save Forests. Protect Wildlife. Build a Sustainable Future.**
